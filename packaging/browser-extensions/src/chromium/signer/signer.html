📚 Ayuda - GrxFirma Dipgra

🔐 Firmar un documento

  1. Selecciona un certificado de la lista
  2. Elige el formato de firma (PAdES para PDFs)
  3. Haz clic en "Seleccionar Documento"
  4. Pulsa "Firmar Documento"
  5. El archivo firmado se descargará automáticamente

✔️ Verificar una firma

  1. Selecciona el formato de validación
  2. Para PAdES: selecciona solo el PDF firmado
  3. Para otros: selecciona documento original y archivo .p7s
  4. Pulsa "Verificar Firma"

⚠️ Solución de problemas

  • No aparecen certificados: Asegúrate de tener certificados instalados en el sistema (DNIe o smart card)
  • Error al firmar: Verifica que el programa nativo está instalado correctamente
  • Archivos grandes lentos: Es normal, se envían por partes para mayor seguridad
