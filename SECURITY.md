# Seguridad

## Versiones compatibles

Las versiones etiquetadas y la rama `main` reciben mantenimiento según la
capacidad del proyecto. Este repositorio no establece plazos de respuesta ni
una política LTS.

## Informar de una vulnerabilidad

Escribe a **avidad@dipgra.es** con el asunto «Seguridad GrxFirma». Describe el
impacto, la versión afectada y los pasos mínimos para reproducir el problema.
No incluyas datos personales, certificados privados ni claves en el mensaje.

Para consultas de soporte y mejoras generales, usa la misma dirección indicando
«Soporte GrxFirma» en el asunto.

## Desarrollo seguro

El proyecto mantiene comprobaciones locales y de CI para pruebas, dependencias
y artefactos de distribución. Las opciones de compatibilidad con algoritmos
antiguos requieren configuración expresa. Consulta la documentación pública de
[política de vulnerabilidades](docs/POLITICA_VULNERABILIDADES.md) y
[arquitectura](docs/ARCHITECTURE.md).
