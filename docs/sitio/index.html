GrxFirma

Firma y verifica documentos con una aplicación de código abierto.

Descargar

Consulta la última versión publicada y elige el paquete de tu plataforma. Comprueba las instrucciones y las sumas de verificación de esa versión antes de instalarla. La política de firma de código explica qué programas se firman y quién lo aprueba.

Los programas de Windows se firmarán con un certificado de SignPath Foundation, que ofrece firma de código gratuita a proyectos de software libre: Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Hay versiones para Windows, Linux y Android. No hay versiones para Mac ni iPhone: no dispongo de esos equipos para compilarlas y probarlas. Si quieres que existan, préstame o regálame uno y me pongo con ello 😄 (avidad@dipgra.es). Hay trabajo hecho, pero sin probar ni terminar: a la versión de Mac le falta aproximadamente un 25 % y a la de iPhone, un 65 %.

Extensión de navegador

La extensión conecta los sitios autorizados con GrxFirma instalado en el equipo. Necesita la aplicación de escritorio para firmar.
