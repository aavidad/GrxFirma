GrxFirma

Política de firma de código

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

SignPath.io ofrece la firma de código sin coste y el certificado es de SignPath Foundation. Por eso Windows muestra «SignPath Foundation» como editor de los programas de GrxFirma.

Qué se firma

Se firman con Authenticode los programas de GrxFirma para Windows que se publican en las versiones oficiales:

  • los instaladores (*-setup.exe) y los desinstaladores que llevan dentro;
  • los ejecutables y bibliotecas de los paquetes ZIP;
  • las bibliotecas de terceros que se distribuyen sin firma de su fabricante.

Las bibliotecas que ya vienen firmadas por su fabricante, como las de Microsoft, conservan esa firma y no se vuelven a firmar.

Solo se firma lo que compila el flujo público release.yml de GitHub Actions a partir de una etiqueta de versión que ya está en la rama principal. Cada firma lleva un sello de tiempo. Antes de publicar, otro equipo sin acceso a la firma comprueba de nuevo todas las firmas y las sumas SHA-256. Las sumas de cada versión se publican firmadas con OpenPGP.

La aplicación Android se firma aparte, con una clave propia del proyecto que no gestiona SignPath.

Privacidad

Los programas firmados no envían información a otros sistemas salvo que lo pida la persona que los usa o quien los instala o administra. Las excepciones son estas:

  • La aplicación de escritorio consulta en GitHub si hay una versión nueva. Esta comprobación viene activada y se puede desactivar en la configuración.
  • Al firmar o verificar, la aplicación puede consultar servicios de sellado de tiempo o de estado de certificados, según la operación y la configuración.

Los documentos y las claves privadas no se envían a servidores de GrxFirma. Los detalles están en la política de privacidad.
