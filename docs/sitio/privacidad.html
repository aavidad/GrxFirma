GrxFirma

Política de privacidad

Aplicación de escritorio y Android

GrxFirma trabaja principalmente en el dispositivo. Trata los documentos que eliges, los certificados que seleccionas y los resultados de firma o verificación para realizar la operación solicitada. Las claves privadas no se envían a servidores de GrxFirma. La aplicación puede consultar servicios de sellado de tiempo o de revocación de certificados según la operación y su configuración. Al sellado de tiempo se envía la huella de la firma, nunca el documento.

En Android, el permiso de Internet solo se usa cuando lo pides: para añadir fecha y hora certificadas, comprobar si un certificado está revocado, cotejar con la Agencia Tributaria el QR de una factura o buscar actualizaciones en GitHub. El cotejo envía a la Agencia Tributaria el NIF del emisor, el número, la fecha y el importe que figuran en el QR, y la aplicación no guarda la respuesta. El permiso NFC sirve para leer el DNIe. Los documentos se abren con el selector del sistema y la aplicación no conserva sus permisos entre sesiones. La aplicación guarda solo sus preferencias, excluidas de las copias de seguridad; no guarda contraseñas, PIN, certificados ni documentos, y no incluye publicidad, analítica ni informes de errores automáticos.

La aplicación de escritorio comprueba si hay una versión nueva consultando las publicaciones de GrxFirma en GitHub. Esa consulta no envía documentos, certificados ni datos personales; GitHub recibe la dirección IP como en cualquier conexión. Viene activada y se puede desactivar en la configuración.

La aplicación de escritorio puede guardar registros operativos y evidencias de auditoría saneadas en el dispositivo. Los registros e incidencias locales tienen límites de tamaño y conservación; no incluyen el documento completo ni contraseñas. Una incidencia solo se envía a soporte mediante una acción expresa del usuario. El organismo que despliegue GrxFirma debe informar de su propio tratamiento y conservación si habilita ese envío.

Extensión de navegador

La extensión no tiene cuenta propia ni envía documentos o datos de uso a servidores de GrxFirma. Al pulsar «Firmar» en un sitio permitido, intenta descargar el PDF con la sesión de ese sitio y pasarlo al firmador local. La precarga temporal se guarda en memoria o en el almacenamiento de sesión y deja de poder utilizarse a los cinco minutos. Se elimina al consumirla, al limpiar solicitudes caducadas o al cerrar la sesión del navegador.

En sitios autorizados, una prueba de identidad requiere la aprobación del usuario. Después, la extensión devuelve al mismo portal el certificado público, su cadena y la firma del reto. El portal aplica su propia política de privacidad. La clave privada no sale del dispositivo.

La extensión conserva localmente los sitios añadidos por el usuario y puede leer los fijados por una organización. Usa permisos de almacenamiento, comunicación con la aplicación local y registro del detector de PDF. Solicita acceso a otros sitios HTTPS cuando el usuario los añade; ese acceso se puede retirar. La extensión no ejecuta código remoto.

La extensión no vende ni cede estos datos, no los usa para publicidad ni para nada distinto de la firma y la prueba de identidad que pide el usuario, y solo los entrega al firmador local o al portal al que el usuario envía la prueba. El uso de la información cumple la política de datos de usuario de Chrome Web Store, incluidos sus requisitos de uso limitado.

Browser extension (English summary)

The extension has no account and sends no documents or usage data to GrxFirma servers. When the user clicks "Sign PDF" on an allowed site, it downloads the PDF with that site's session and hands it to the GrxFirma signer on the same computer. The temporary copy expires after five minutes and is deleted when collected, when expired requests are cleaned up or when the browser session ends.

On authorised portals, an identity proof needs the user's approval. The extension then returns the public certificate, its chain and the challenge signature to that same portal, which applies its own privacy policy. The private key never leaves the device.

The extension stores locally the sites the user adds and can read sites set by an organisation. It asks for access to other HTTPS sites only when the user adds them, and that access can be withdrawn. It runs no remote code. Data is not sold, not transferred to third parties, not used for advertising or creditworthiness, and not used for anything other than the signing and identity proof the user requests. The use of information received complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
